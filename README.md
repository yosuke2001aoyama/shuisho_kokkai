# 国会答弁・質問主意書アーカイブ / 起案支援bot

国民向けには、国会答弁と質問主意書・答弁書を一か所で検索できる公開プラットフォーム。官僚向けには、架空の質問案から、同種の一次資料だけを使って答弁案を立ち上げる起案ワークスペースです。

## 実装済み

- 国会会議録検索システムの発言単位APIをリアルタイム検索
- 衆議院「質問答弁情報」と参議院「質問主意書・答弁書」を別系統で収集・検索
- 「国会答弁」と「質問主意書」を混ぜない検索ルーター
- 国会答弁モードでは「参考」、質問主意書モードでは「用例集」を表示
- 根拠資料の公式原文URL、引用候補、要確認事項を出力
- OpenAI API未設定時は、虚偽の完成文を作らず引用付き起案骨子を出力
- OpenAI API設定時は、Structured Outputsで根拠付き答弁案を生成
- 入力長制限、サーバー側APIキー、`store: false`、公開情報限定の注意表示
- 全回次を段階的に取得する、再開可能・逐次アクセス型の収集スクリプト

## 起動

Node.js 20以上だけで動作し、外部npmパッケージは不要です。

```bash
cp .env.example .env.local
node server.mjs
```

ブラウザで `http://localhost:3000` を開きます。

環境変数を読み込む場合：

```bash
set -a; source .env.local; set +a
node server.mjs
```

## AI起案を有効化

`.env.local` にサーバー側のAPIキーを設定します。

```env
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5-mini
```

APIキーはブラウザへ送信されません。Responses APIには `store: false` を指定しています。ただし、実運用では組織のデータ保持設定、情報セキュリティ規程、入力禁止情報を別途確認してください。

## 全件索引の構築

公式サイトへの負荷を避けるため、既定で3.2秒以上の間隔を空け、逐次アクセスします。中断しても既存IDを読み込み、続きから再開します。

質問主意書・答弁書：

```bash
node scripts/ingest-written-questions.mjs --from=1 --to=221 --delay=3200
```

国会会議録：

```bash
node scripts/ingest-speeches.mjs --from=1 --to=221 --delay=3200
```

本番では、JSONLをPostgreSQL等へ投入し、全文検索・ベクトル検索を組み合わせることを推奨します。現行MVPは `data/written-index.jsonl` を自動読込します。

## デプロイ

`vercel.json` と `/api/*.mjs` を含むため、Vercelにそのまま接続できます。静的画面は `/public`、APIはNode.js Serverless Functionsです。

必要な環境変数：

- `OPENAI_API_KEY`（任意）
- `OPENAI_MODEL`（任意）
- `LATEST_DIET_SESSION`
- `WRITTEN_SCAN_SESSIONS`

## 生成時の不変条件

1. 国会答弁案には国会会議録の発言を優先する。
2. 質問主意書答弁書案には質問主意書の答弁書を優先する。
3. 提示された一次資料にない事実、数字、政策方針を創作しない。
4. 資料不足時は、完成文ではなく要確認又はプレースホルダーを残す。
5. すべての主要な根拠から公式原文へ遷移できるようにする。
6. 生成結果を正式な政府見解と表示しない。

## 一次資料

- 国立国会図書館「国会会議録検索システム」
- 衆議院「質問答弁情報」
- 参議院「質問主意書・答弁書」

各サイトの利用条件を遵守し、短時間の大量アクセスや多重リクエストを行わないでください。
